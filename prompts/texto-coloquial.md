# Prompt preset: Texto coloquial

Seleccionable en Handy → Post-processing → Prompts (sustituye temporalmente al maestro).

```
<transcript>
${output}
</transcript>

Redacta un mensaje COLOQUIAL con el contenido del dictado anterior: como si el propio usuario lo contara hablando, en primera persona, cercano y sencillo, sin tecnicismos, sin saludos rígidos ("Estimado") ni estructura de carta. En español, texto plano sin markdown ni asteriscos. Devuelve SOLO el mensaje.
```
